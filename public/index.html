Request pipeline

client ─► auth (SHA-256 key lookup) ─► token bucket (Redis Lua, atomic) ─► input guardrail
       ─► cache (tenant-scoped, temp 0 only) ─► router ─► circuit breaker ─► provider A ─╮
                                                                          fallback ─► provider B
       ◄─ SSE stream with backpressure ◄─ streaming canary filter ◄───────────────────────╯
       └─► batched usage metering (Postgres) · Prometheus metrics
Atomic rate limitingToken bucket in a Redis Lua script, so limits hold across many gateway instances.
Fallback + circuit breakersA failing provider is skipped in milliseconds instead of costing every request a timeout.
Streaming guardrailsSecrets are caught even when split across stream chunks, before they reach the client.
Tenant-scoped cacheIdentical deterministic requests are served from Redis without leaking across tenants.
